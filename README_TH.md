ระบบนี้ออกแบบมาเพื่อให้มองเห็นสถานะเงินเดินทางของอาจารย์แต่ละคน โดยแสดงรอบการเงิน งบประมาณ ยอดใช้ และเงินคงเหลือ

## 📋 ความเข้าใจพื้นฐาน

### วัฏจักรเงินเดินทาง (Budget Cycle)

- **เงินเข้า (Budget In):** เมื่ออาจารย์ได้รับเงินอุดหนุน (ปกติ 120,000 บาท)
- **รอบบัญชี:** เริ่มจากวันที่เงินเข้า จนกว่าจะมีเงินเข้าอีกรอบ
- **การคำนวณ:** เงินคงเหลือ = เงินเข้า − (ยอดใช้) − (เบิกคืน)

### ตัวอย่างจริง: อาจารย์ KR

```
รอบที่ 1 (01-08-2024 ถึง 14-11-2024)
├─ เงินเข้า:   120,000 บาท
├─ ยอดใช้:     120,000 บาท
├─ เบิกคืน:    0 บาท
└─ คงเหลือ:    0 บาท

รอบที่ 2 (15-11-2024 ถึงปัจจุบัน)
├─ เงินเข้า:   120,000 บาท
├─ ยอดใช้:     65,241 บาท
├─ เบิกคืน:    54,759 บาท (08-02-26)
└─ คงเหลือ:    0 บาท (120,000 − 65,241 − 54,759)
```

## 🔢 สูตรการคำนวณ

```
เงินคงเหลือ = เงินเข้า − ยอดใช้ − เบิกคืน
```

### แยกประเภท

- **ยอดใช้ = กรณี1 + กรณี2.1 + กรณี2.2 + กรณี3**
- **เบิกคืน = เงินที่คืนเข้าระบบ (Template: return money to system)**

### ตัวอย่างคำนวณ KR รอบที่ 2

```
เงินเข้า       = 120,000 บาท
ยอดใช้        = 65,241 บาท
  ├─ กรณี 2.1 = 65,241 บาท (ต่างประเทศ + นำเสนอ)
  ├─ กรณี 1   = 0 บาท
  ├─ กรณี 2.2 = 0 บาท
  └─ กรณี 3   = 0 บาท
เบิกคืน       = 54,759 บาท (08-02-26)
───────────────────────────────
คงเหลือ = 120,000 − 65,241 − 54,759 = 0 บาท ✓
```

## 📝 ประเภทของการเบิก (ส่งผลต่อแดชบอร์ด)

### 1️⃣ Debt Template (ตั้งหนี้)

- **ไม่แสดง** ในแดชบอร์ด (ยังไม่ใช้จ่ายจริง)

### 2️⃣ Travel Template (รายงานค่าใช้จ่าย)

- **แสดงในแดชบอร์ด** ในตัวอักษร: ไม่ระบุ, ต่างประเทศ, ใน ประเทศ ฯลฯ
- นับในยอดใช้ (ยอดใช้รวม)
- นับในประเภท (กรณี1-3)

### 3️⃣ Return Money to System (คืนเงิน)

- **แสดงในแดชบอร์ด** เป็น: "เบิกเงินคืน"
- นับใน "เบิกคืน" แต่ **ไม่ใช่** ในยอดใช้
- ลดเงินคงเหลือลง

### 4️⃣ เงินเข้า 120000 (เงินอุดหนุนเข้า)

- **ไม่แสดง** ในแดชบอร์ด (แต่สร้าง รอบใหม่)
- ใช้เพื่อแบ่งระหว่างรอบ

## 🚨 โน้ต ที่สำคัญ

### ⚠️ เงินคงเหลือ = เป้าหมายของระบบ

- ควรเป็น **0** เมื่อจบรอบ
- ถ้า **ไม่เป็น 0**:
  - อาจารย์ยังมีหนี้ (Debt Template ที่ยังไม่ชำระ)
  - หรืออาจารย์ยังมีเงินคงเหลือ (ต้องคืน)

### ⚠️ วันที่ที่สำคัญ

- Dashboard เทียบกับวันที่ปัจจุบัน (วันนี้: 08-02-2026)
- **ไม่นับ** GL Entry ที่มีวันที่ > วันนี้ (ป้องกันการบิดเบือน)

### ⚠️ การใช้งานถูกต้อง

1. เบิกเงิน → ใช้ Travel Template ให้ชัดเจน
2. ไม่อนุมัติ Travel Template บ่อยเกินไป (ป้องกันความสับสน)
3. ตรวจสอบ Dashboard ทุกเดือน
